CSS Box-Sizing Comparison

content-box

Width: 250px | Padding: 30px | Border: 10px

Total Width = 330px

border-box

Width: 250px | Padding: 30px | Border: 10px

Total Width = 250px

Explanation

content-box adds padding and border outside the width. border-box includes padding and border inside the defined width.

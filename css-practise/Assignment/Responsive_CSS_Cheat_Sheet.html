Responsive CSS Cheat Sheet

Filters

Modify visual rendering of elements. E.g., filter: blur(5px);

Media Queries

Apply CSS based on viewport width. E.g., @media (max-width: 700px) {...}

Flexbox

1D layout model for alignment. E.g., display: flex; justify-content: center;

CSS Grid

2D layout model. E.g., display: grid; grid-template-columns: 1fr 1fr;

Typography

Fluid sizing using math. E.g., font-size: clamp(1rem, 2vw, 2rem);

1. Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.

Frontend Development:
Frontend is the part of a website that users can see and interact with. It is created using HTML, CSS, and JavaScript.

Example: The login page of Instagram or Facebook.

Backend Development:
Backend is the server-side part that manages data, authentication, and business logic. It is developed using languages like Java, Python, PHP, or Node.js.

Example: Checking the username and password when a user logs in.

Full-Stack Development:
A Full-Stack Developer works on both frontend and backend.

Example: Building a complete online shopping website from user interface to database.

3. Describe how a browser requests and displays a web page from a web server.
The user enters a website URL.
The browser sends an HTTP request to the web server.
The server processes the request.
The server sends HTML, CSS, and JavaScript files.
The browser renders the webpage and displays it to the user.
